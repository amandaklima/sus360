SUS360 

Objetivo: Plataforma digital colaborativa que compara o serviço oficialmente informado pelo SUS com a experiência relatada pelos cidadãos, gerando transparência, dados confiáveis e subsídios para a melhoria da gestão pública em saúde.

Tecnologias

React

JavaScript

Vite

Node.js

Como executar o front-end

É necessário ter o Node.js instalado.

cd 360
npm install
npm run dev


A aplicação estará disponível em:

http://localhost:5173/
