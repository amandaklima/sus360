📌 Sobre o projeto

O SUS360 é uma plataforma digital colaborativa que busca promover mais transparência e qualidade nos serviços públicos de saúde.

A proposta é comparar as informações oficialmente disponibilizadas pelo Sistema Único de Saúde (SUS) com as experiências relatadas pelos cidadãos, permitindo identificar possíveis divergências entre o serviço informado e o atendimento vivenciado pela população.

A plataforma pretende contribuir para a geração de dados confiáveis, o fortalecimento da participação cidadã e a identificação de oportunidades de melhoria na gestão pública em saúde.

Objetivos
Promover a transparência: facilitar a comparação entre os serviços oficialmente informados e a experiência dos cidadãos.
Incentivar a participação cidadã: permitir que a população contribua com relatos sobre os serviços de saúde.
Gerar informações relevantes: organizar dados que ajudem a identificar problemas e oportunidades de melhoria.
Apoiar a gestão pública: oferecer subsídios para aprimorar a qualidade dos serviços prestados à população.
 Tecnologias utilizadas

O projeto utiliza as seguintes tecnologias:

React — desenvolvimento da interface de usuário.
JavaScript — implementação da lógica e das funcionalidades da aplicação.
Vite — ferramenta de desenvolvimento e build do front-end.
Node.js — ambiente necessário para executar as ferramentas de desenvolvimento.
 Como executar o front-end
Pré-requisitos
Antes de começar, certifique-se de ter instalado:

Node.js
npm, que normalmente é instalado junto com o Node.js.
Instalação e execução
Clone o repositório:
git clone https://github.com/amandaklima/sus360.git

Acesse a pasta do projeto:
cd 360

Instale as dependências:
npm install

Inicie o servidor de desenvolvimento:
npm run dev

Acesse a aplicação pelo navegador:

http://localhost:5173/

Observação: substitua URL_DO_REPOSITORIO pelo endereço real do repositório no GitHub. Caso a pasta do projeto tenha outro nome, ajuste o comando cd 360.

O SUS360 está em fase de desenvolvimento, com foco na construção de uma plataforma que conecte informações sobre os serviços públicos de saúde às experiências dos cidadãos.
